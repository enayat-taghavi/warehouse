# طرح جامع احیا و بازنشانی استاندارد دوربین اسکنر بارکد بر پایه معماری سالم گیت

این طرح به منظور **بازگرداندن معماری پایدار، استاندارد و بدون خطای دوربین اسکنر بر اساس نسخه سالم اولیه گیت (کامیت `5b66605`) و ارتقای همزمان آن برای پشتیبانی از تمامی فرمت‌های بارکد ۱ بعدی و ۲ بعدی صنعتی** تدوین شده است.

---

## ۱. تحلیل و چرایی بازنشانی (Rationale & Architecture Review)

| بخش | وضعیت فعلی (دارای اختلال و صفحه سیاه) | معماری بازنشانی‌شده استاندارد (برگرفته از گیت) |
| :---: | :--- | :--- |
| **موتور استریم ویدیو** | تلاش دستی برای کراپ روی بوم نامرئی (Offscreen Canvas) در هر فریم که باعث اختلال در چرخه اتصال ویدیو و سیاه ماندن صفحه می‌شود. | واگذاری کامل هندلینگ استریم، رزولوشن و رندر بلادرنگ روی تگ `<video>` به متد بومی و پایدار **`decodeFromConstraints`** و **`BarcodeDetector`**. |
| **پشتیبانی از انواع بارکد** | استفاده از مدل QR تکی در نسخه قدیمی | ارتقا به **`BrowserMultiFormatReader`** با پوشش کامل ۱۲ فرمت صنعتی (QR, Code 128, EAN-13, Data Matrix, Code 39, ...) |
| **مدیریت منابع و حافظه** | تداخل در متغیرهای `MediaStream` و متوقف نشدن کامل دوربین | کنترل یکپارچه چرخه حیات با شیء رسمی **`IScannerControls`** و متوقف‌سازی بی‌نقص تمام Trackها هنگام بستن دوربین |
| **رابط کاربری و اورلی** | لایه‌های پیچیده CSS که مانع مشاهده ویدیو می‌شدند | اورلی سبک و مدرن شیشه‌ای، خط راداری لیزر، راهنمای واضح و دکمه بستن با کلید `Escape` |
