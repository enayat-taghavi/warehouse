## برنامه تست و تأیید (Verification Plan)

### تست‌های دستی
- کلیک روی دکمه شروع آپلود با اینپوت تگ خالی -> باید مودال هشدار باز شود.
- کلیک روی «ادامه بدون تگ» در مودال -> باید آپلود شروع شود.
- درج تگ به صورت `تگ۱,تگ۲،تگ۳` در اکسل -> باید در بک‌اند به درستی سه تگ مجزا پردازش شود.
- وارد کردن فایل اکسل برای کالایی که از قبل تگ دارد -> تگ‌های قبلی نباید پاک شوند، بلکه تگ جدید به انتهای آن‌ها اضافه گردد.
