# راهنمای تست دستی نسخهٔ اول (قدم به قدم)

نشانی پایه: `https://app.farsalish.ir`

**روش کار:**
- هر قدم را به ترتیب انجام دهید.
- در ستون «نتیجه» بنویسید ✅ یا ❌.
- اگر ایرادی دیدید، یک توضیح کوتاه بنویسید و عکس صفحه را هم نگه دارید.
- اگر صفحه‌ای با نوشتهٔ این راهنما فرق داشت، همان را بنویسید تا راهنما را درست کنم.

**بخش‌هایی که فعلاً تست نمی‌شوند** (هنوز ساخته نشده‌اند):
- پروندهٔ پرسنلی؛
- کارکرد؛
- حقوق؛
- ناوگان؛
- گزارش‌ها.

## بخش ۱. کاربران، شرکت و دسترسی

**هدف:** یک شرکت تست با یک پروژه و دو بخش بسازید. بعد برای هر نقش یک کاربر بسازید. این کاربرها در بخش‌های بعدی (فاکتور و تنخواه) هم لازم‌اند.

**کاربرهایی که می‌سازید:**
- برای همه رمز ساده و آزمایشی بگذارید، نه رمز واقعی خودتان.
- رمزها را جایی یادداشت کنید.

| نام کاربری | نقش | بخش |
|---|---|---|
| `t_employee` | کارمند (ثبت‌کننده) | بخش الف |
| `t_supervisor` | سرپرست بخش | بخش الف |
| `t_accountant` | حسابدار | کل پروژه |
| `t_manager` | مدیر (تأیید نهایی) | کل شرکت |
| `t_treasury` | خزانه‌دار | کل شرکت |
| `t_employee2` | کارمند | بخش ب (برای این‌که ببینیم بخش الف را نمی‌بیند) |

## بخش اندروید. اپ اندروید روی گوشی

**هدف:** اپ آزمایشی را روی گوشی واقعی خودتان نصب کنید و با **اینترنت همراه ایرانی** (سیم‌کارت، نه وای‌فای) و **بدون فیلترشکن** امتحان کنید. این قسمت را فقط شما می‌توانید انجام دهید؛ بقیه روی شبیه‌ساز گوشی آزموده شده است.

**پیش از شروع:**
- فیلترشکن گوشی را خاموش کنید.
- وای‌فای را خاموش و اینترنت همراه را روشن کنید.
- اگر نسخهٔ آزمایشی قبلی روی گوشی هست، پاکش نکنید؛ نسخهٔ تازه باید روی همان نصب شود.

| # | چه کار کنید | چه چیزی باید ببینید | نتیجه |
|---|---|---|---|
| الف.۱ | با مرورگر گوشی [فایل نصب اپ آزمایشی](https://app.farsalish.ir/api/public/mobile-files/apk/CoManage-1.0.0-direct-test.apk) را بگیرید و نصب کنید (اگر گوشی پرسید، اجازهٔ نصب از این مرورگر را بدهید) | اپ بی خطا نصب شود؛ اگر نسخهٔ قبلی بود، روی آن نصب شود | |
| الف.۲ | اپ را باز کنید و با `t_employee` وارد شوید | صفحهٔ اول بی خطا بیاید | |
| الف.۳ | منوی کاربر (بالای صفحه) را باز کنید | سطر «نسخهٔ ۱٫۰٫۰» دیده شود | |
| الف.۴ | اگر نسخهٔ قبلی را به‌روز کردید: بار اول باز کردن را نگاه کنید | پنجرهٔ «چه چیزی تازه است» فقط **یک بار** بیاید؛ بار بعد نیاید | |
| الف.۵ | یک پنجره (مثلاً فرم ثبت) را باز کنید و دکمهٔ برگشت گوشی را بزنید | اول همان پنجره بسته شود، نه این‌که اپ بیرون برود | |
| الف.۶ | به من بگویید تا یک اعلان آزمایشی برای `t_employee` بفرستم (یا هر کار دیگری که اعلان می‌سازد) | اعلان در نوار بالای گوشی بیاید و با لمس آن «کارهای من» باز شود. اگر روی گوشی نیامد ولی زنگولهٔ داخل اپ آن را داشت، فقط بنویسید (روی شبکهٔ ایران تضمین نیست) | |
| الف.۷ | حالت هواپیما را روشن کنید، یک هزینهٔ تنخواه و یک پیش‌نویس فاکتور ثبت کنید | ثبت شود و پیام «در صف ارسال» یا مانند آن بیاید | |
| الف.۸ | اپ را کامل ببندید (از فهرست برنامه‌های باز بیرون بکشید) و دوباره باز کنید | دو مورد هنوز در صف باشند | |
| الف.۹ | حالت هواپیما را خاموش کنید و اپ را جلو بیاورید | چند ثانیه بعد صف خالی شود و هزینه و فاکتور در فهرست بیایند؛ چیزی گم نشود | |
| الف.۱۰ | اگر نوار «نسخهٔ تازه آماده است» آمد، دکمهٔ «به‌روزرسانی» را بزنید | اپ دوباره بار شود و داده‌ها سر جایشان باشند | |

**پس از این بخش:** نتیجه‌ها (به‌خصوص الف.۶ و الف.۹) را برایم بفرستید.
