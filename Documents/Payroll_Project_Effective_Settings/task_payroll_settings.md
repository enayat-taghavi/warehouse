  - **فیلدهای مدل [PayrollYearlySettings](file:///e:/warehouse%20project/backend/personnel/models.py#L1587):**

## 📌 فاز ۲: ارتقای موتور محاسبات حقوق و حذف هاردکدهای مالیاتی (Calculation Engine)

### تسک ۲.۱: متد هوشمند واکشی تنظیمات منطبق بر پروژه و ماه کارکرد
- **توضیح خیلی خیلی ساده:**  
  موتور محاسبه حقوق وقتی می‌خواهد حقوق کارمند را برای یک ماه (مثلاً آبان) حساب کند، چک می‌کند کارمند در چه پروژه‌ای است و آخرین احکام معتبر تا ماه آبان برای آن پروژه چیست. اگر پروژه احکام اختصاصی نداشت، احکام کل شرکت در همان ماه را اعمال می‌کند.
- **جزئیات فنی:**  
  - **فایل مقصد:** `backend/personnel/payroll_engine.py`
  - ایجاد متد بهینه‌شده:
    ```python
    def get_effective_payroll_settings(year_month: str, project_id: int = None) -> PayrollYearlySettings:
        # 1. تنظیمات اختصاصی پروژه در بازه معتبر
        if project_id:
            qs = PayrollYearlySettings.objects.filter(
                project_id=project_id,
                effective_from__lte=year_month
            ).filter(
                Q(effective_to__gte=year_month) | Q(effective_to__isnull=True)
            ).order_by('-effective_from').first()
            if qs:
                return qs

        # 2. ارث‌بری هوشمند از تنظیمات سراسری سازمان در همان بازه
        global_qs = PayrollYearlySettings.objects.filter(
            project__isnull=True,
            effective_from__lte=year_month
        ).filter(
            Q(effective_to__gte=year_month) | Q(effective_to__isnull=True)
        ).order_by('-effective_from').first()
        if global_qs:
            return global_qs

        # 3. فال‌بک نهایی به فعال‌ترین رکورد سال
        year_str = year_month.split('/')[0] if '/' in year_month else '1405'
        return PayrollYearlySettings.objects.filter(fiscal_year=year_str, is_active=True).first()
    ```
  - اتصال این متد درون متد `calculate_period` به ازای پروژه هر پرسنل.
