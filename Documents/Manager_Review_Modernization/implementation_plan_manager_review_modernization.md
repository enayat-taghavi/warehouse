# برنامه جامع پیاده‌سازی همگام‌سازی و نوسازی کارتابل بررسی نهایی مدیر (`Manager Review Modernization Implementation Plan`)

<div dir="rtl" align="right">

این مستند نقشه راه جامع و مهندسی شده برای نوسازی ساختار تب «بررسی نهایی مدیر» (`Manager Review`) بر پایه آخرین استانداردها، ساختار ماژولار و ۲۴ ویژگی پیشرفته پیاده‌شده در «کارتابل سرپرست» (`Supervisor Cartable`) را تشریح می‌کند.

---

## 🎯 اهداف کلیدی و رویکرد طراحی

1. **کپی شاسی و ساختار مدرن (`Cloning Modern UI Framework`):** انتقال تمام کامپوننت‌های مدرن، لایه‌بندی بصری، تقویم شمسی جلالی (`PersianDatePipe`)، پایداری وضعیت در `LocalStorage` و `URL State`، چیپ‌های لوکیشن، دراپ‌دان سورت هوشمند و بارکد اسکنر.
2. **بومی‌سازی و حفظ منطق تجاری مدیر (`Manager Domain Logic Adaptation`):** حفظ دقیق وضعیت‌های فرآیندی (`MANAGER_REVIEW`, `FINAL_APPROVED`, `MANAGER_REJECTED`)، اندپوینت‌های API مدیر (`bulk_manager_approve`, `bulk_manager_reject`)، اکشن‌های استخر مدیر (`as_role='manager'`) و مجوزهای امنیتی مربوطه.
3. **ارزیابی ایجنت نگهبان مستقل در هر فاز (`Independent Guardian Agent Reviews`):** بررسی سلامت ساختار در پایان هر فاز قبل از ورود به فاز بعدی.

## 🛡️ پروتکل بازبینی ایجنت نگهبان مستقل (Guardian Protocol)

در پایان هر یک از فازها، ایجنت نگهبان به طور مستقل موارد زیر را ارزیابی خواهد کرد:
1. عدم تخریب یا حذف ناخواسته کدهای مرتبط با سایر بخش‌ها.
2. تطابق ۱۰۰٪ وضعیت‌ها، مجوزها و اندپوینت‌های مدیر.
3. عدم وجود خطاهای کامپایل تایپ‌اسکریپت و کدهای شکسته در تمپلیت.
4. سلامت تست‌های بک‌اند.
