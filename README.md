## 🌟 ویژگی‌ها و ماژول‌های کلیدی

### ۱. هسته انبارداری و انبارگردانی (`warehouses` & `inventory`)
- مدیریت چندانباره با امکان تخصیص کاربران و دسترسی‌های تفکیک‌شده به هر انبار.
- صدور اسناد ورود (رسید)، خروج (حواله)، جابجایی بین انبارها و مرجوعی.
- فرآیند انبارگردانی دوره‌ای چندمرحله‌ای (شمارش اول، دوم، سوم، مقایسه مغایرت‌ها و ثبت کسری/اضافی).
- بارکدخوان و QR-Code خوان داخلی یکپارچه تحت وب برای تسریع شمارش و ثبت پالت‌ها.

### ۲. کارتابل هوشمند و تأییدیه اسناد (`cartable`)
- جریان کار (Workflow) چندسطحی برای بررسی و تأیید اسناد انبار توسط سرپرستان و مدیران.
- قفل‌های همزمانی و تراکنش‌های امن (`select_for_update`) جهت پیشگیری از Race Condition در ثبت اسناد.

### ۳. حسابداری پرسنلی، حضور و غیاب و حقوق (`personnel`)
- **تطابق کامل با استاندارد مالی:** محاسبات منطبق بر ساختار فرمول‌های کارشناسی (پایه کارکرد ۱۰ ساعت روزانه، اضافه کاری، حق مسکن، خواربار، اولاد و بن کارگری).
- سیستم ثبت و ویرایش ارگونومیک حضور و غیاب روزانه با کلیدهای میانبر کیبورد.
- **تولید دیسکت‌های قانونی:** ایجاد خودکار فایل‌های استاندارد دیسکت بیمه تأمین اجتماعی (`DSKWOR00.DBF`, `DSKKAR00.DBF`) و فایل‌های مالیات بر درآمد حقوق (`WH`/`WP`).
- **اعتبارسنجی یکپارچه بانکی:** سیستم دوطرفه استخراج و تبدیل شماره حساب به شبا (الگوریتم ISO 7064 Mod 97) و شناسایی خودکار بانک‌های کشور.

### ۴. ترابری و مدیریت ناوگان (`fleet`)
- ثبت رانندگان، خودروها، مسیرهای تردد و سرویس‌های پرسنلی و باری.
- صدور و پیگیری صورت‌حساب‌های ماهانه و محاسبات تسویه‌حساب پیمانکاران حمل‌ونقل.

### ۵. معماری آفلاین و همگام‌سازی تاب‌آور (Offline-First PWA)
- عملکرد کامل در مناطق با پوشش ضعیف اینترنت (Lie-Fi) و قطعی شبکه از طریق دیتابیس لوکال کلاینت (IndexedDB با `Dexie.js`).
- صف‌بندی عملیات‌های ثبت کلاینت و همگام‌سازی هوشمند دوطرفه بدون از دست رفتن رکوردها (Zero Data Loss).
- سازگاری کامل با تونل‌های دسترسی امن (مانند Cloudflare Tunnel).

### ۶. ارتباطات بلادرنگ و گزارش‌ساز (`communications` & `reports`)
- اعلان‌ها (Notifications) و وب‌سوکت‌های زنده برای آگاهی آنی از تغییرات اسناد و تأییدیه‌ها.
- ماژول چت سازمانی متصل به پایگاه داده.
- خروجی استاندارد دو سطحی اکسل با فریز پنل و تاریخ شمسی به همراه تولید اسناد چاپی و PDF.

## 🏛 معماری سیستم و ساختار مخزن

پروژه به صورت یک مخزن یکپارچه (Monorepo) با استراتژی تفکیک ماژولار پیاده‌سازی شده است:

```text
├── warehouse-backend/               # هسته بک‌اند بر پایه Django 5 و Django REST Framework
│   ├── config/                      # تنظیمات مرکزی پروژه، پیکربندی ASGI/WSGI و URLهای پایه
│   ├── settings_core/               # تنظیمات سیستمی پلتفرم و ماژول‌های فعال
│   ├── warehouses/                  # هسته مدیریت انبارها و تعریف ساختار فیزیکی
│   ├── inventory/                   # کالاها، دسته‌بندی‌ها، اسناد انبارداری و شمارش موجودی
│   ├── personnel/                   # مدیریت پرسنل، حضور و غیاب، حقوق و دستمزد و ناوگان
│   ├── accounts/                    # کاربران، نقش‌ها (RBAC)، ممیزی (Audit Log) و سشن‌ها
│   ├── communications/              # سیستم چت و پیام‌رسانی داخلی بر بستر وب‌سوکت
│   ├── notifications/               # موتور اعلان‌ها و هشدارها
│   └── reports/                     # موتور گزارش‌ساز پیشرفته اکسل و PDF
│
├── warehouse-front/                 # فرانت‌اند مدرن Single Page Application با Angular 22
│   ├── src/app/components/          # کامپوننت‌های ماژول‌های انبارداری، حسابداری، پرسنلی و ناوگان
│   ├── src/app/core/services/       # سرویس‌های زیرساختی، آفلاین، سینک و ارتباط با سرور
│   └── tools/patch-ngsw-530.js      # پچ نگهبان Service Worker برای پایداری در تونل شبکه
│
├── scripts/                         # اسکریپت‌های آزمون‌های سرتاسری و نگهبان‌های ماژولارسازی (E2E & Guardians)
├── start.bat                        # لانچر سریع برای اجرای همزمان سرویس‌ها
└── dev-manager-modular.bat          # منیجر چندمنظوره برای مدیریت محیط‌های تفکیک‌شده
```

## ⚙️ پیش‌نیازهای سیستمی

قبل از اجرای پروژه، مطمئن شوید ابزارهای زیر بر روی سیستم نصب هستند:

1. **Python:** نسخه `3.11` یا بالاتر (در ویندوز تیک `Add Python to PATH` فراموش نشود).
2. **Node.js:** نسخه `v20.x` یا بالاتر (به همراه `npm` نسخه ۹ به بالا).
3. **Git:** آخرین نسخه جهت دریافت و به‌روزرسانی کدها.

## 🚀 راه‌اندازی سریع (Quick Start)

در محیط ویندوز، برای اجرای سریع و خودکار هر دو سرور، کافیست فایل زیر را اجرا کنید:

```cmd
start.bat
```
این اسکریپت بک‌اند جنگو را روی پورت `8000` و فرانت‌اند انگولار را روی پورت `4200` در دو پنجره مجزا اجرا کرده و سامانه بلافاصله آماده بهره‌برداری می‌شود.

همچنین برای دسترسی به منوی پیشرفته مدیریت محیط‌ها (شامل حالت فقط انبارداری، فقط حسابداری و اجرای نگهبان‌ها):
```cmd
dev-manager-modular.bat
```

## 🛠 راه‌اندازی دستی و گام‌به‌گام

### ۱. بک‌اند (`warehouse-backend`)

۱. وارد پوشه بک‌اند شوید:
```bash
cd warehouse-backend
```

۲. محیط مجازی پایتون (Virtual Environment) ایجاد و فعال کنید:
```bash
# ویندوز (PowerShell / CMD)
python -m venv venv
.\venv\Scripts\activate

# لینوکس و مک
python3 -m venv venv
source venv/bin/activate
```

۳. نیازمندی‌های پایتون را نصب کنید:
```bash
pip install -r requirements.txt
```

۴. ساخت دیتابیس، اعمال مایگریشن‌ها و ایجاد داده‌های اولیه تست:
```bash
python manage.py setup_project
```
*(این دستور به شکل هوشمند دیتابیس را ساخته و کاربران و نقش‌های تستی را بارگذاری می‌کند).*

۵. اجرای سرور توسعه جنگو:
```bash
python manage.py runserver 8000
```
> سرور بک‌اند در نشانی `http://127.0.0.1:8000` در دسترس خواهد بود.

---

### ۲. فرانت‌اند (`warehouse-front`)

۱. یک پنجره ترمینال جدید باز کرده و وارد پوشه فرانت‌اند شوید:
```bash
cd warehouse-front
```

۲. وابستگی‌های نود را نصب نمایید:
```bash
npm install
```

۳. اجرای سرور انگولار:
```bash
npm run start
```
> اپلیکیشن در نشانی `http://localhost:4200` قابل مشاهده و استفاده خواهد بود.

## 🎛 پروفایل‌های اجرای تفکیک‌شده (Modular Builds)

بر اساس معماری تفکیک ماژول‌ها، می‌توانید فرانت‌اند را به صورت اختصاصی برای بخش‌های مختلف اجرا یا بیلد کنید:

| دستور | کاربرد |
| :--- | :--- |
| `npm run start` | اجرای کل سامانه (جامع - انبارداری و حسابداری) |
| `npm run start:warehouse` | اجرای سبک با تمرکز صرف روی ماژول انبارداری |
| `npm run start:accounting` | اجرای تفکیک‌شده برای امور مالی، پرسنلی و ترابری |
| `npm run build` | بیلد کامل برای محیط پروداکشن (به همراه پچ Service Worker) |
| `npm run build:warehouse` | بیلد نسخه مستقل انبار |
| `npm run build:accounting` | بیلد نسخه مستقل حسابداری و پرسنلی |

## 🧪 تست‌ها و نگهبان‌های کیفیت (Quality Assurance)

سامانه از سطوح چندگانه تست خودکار برای تضمین پایداری بهره می‌برد:

### تست‌های فرانت‌اند (DOM Unit Testing با Vitest)
برای اجرای سریع تست‌های اجزای فرانت‌اند و کامپوننت‌های Angular بدون نیاز به مرورگرهای سنگین:
```bash
cd warehouse-front
npm run test
```

### تست‌های بک‌اند و نگهبان‌های معماری (Guardians)
برای بررسی سلامت ماژول‌ها و عدم شکستن مرزهای معماری بین اپلیکیشن‌ها:
```bash
# اعتبارسنجی وابستگی‌های بین‌ماژولی با Import Linter
python scripts/e2e/guardian_modularization.py

# اجرای کلیه نگهبان‌ها
python scripts/e2e/guardian_all.py

# تست‌های سیستمی جنگو
cd warehouse-backend
python manage.py test
```

## 📌 استانداردها و نکات فنی کلیدی

1. **حفظ یکپارچگی داده‌ها (Zero Data Loss):** کش کلاینت تاریخ‌گذشته هرگز بدون دریافت پاسخ موفقیت قطعی (2xx) از سرور پاک نمی‌شود؛ پاسخ‌های موقت سرور منتهی به تلاش مجدد (Retry) در صف کلاینت خواهند شد.
2. **پایداری شبکه و مدیریت ارورهای لایه پروکسی:** کدهای وضعیت `520` تا `530` در کلاینت به عنوان خطای قطع مبدا/تونل دسته‌بندی شده و تداخل در لاگیک بیزینسی ایجاد نمی‌کنند.
3. **فرمول‌های مالی و قوانین پرسنلی:** تمامی لاگیک‌های پرداخت و مالیات مستقیماً منطبق با جداول کارشناسی و فیش‌های استاندارد سازمانی است.
4. **طراحی واکنش‌گرا و تجربه کاربری (UI/UX):** استفاده از فونت‌های استاندارد فارسی، تم‌های مدرن و استیک بار ارگونومیک در صفحات و کارتابل‌ها برای نهایت سهولت کار با کیبورد و موبایل.
